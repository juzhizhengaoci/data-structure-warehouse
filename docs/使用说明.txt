二、怎么写代码、怎么编译
----------------------------------------------------------------
  工作目录：D:\数据结构课设\code\

  方式 1（推荐，VS Code）
    1) 用 VS Code 打开文件夹  D:\数据结构课设\code
    2) 写 .c / .h 文件（多个文件会自动一起编译）
    3) 按 Ctrl+Shift+B   → 编译，生成 app.exe
    4) 按 F5               → 编译并启动 gdb 调试

  方式 2（双击）
    双击 code\build.bat   → 编译
    双击 code\run.bat     → 编译并运行

  方式 3（命令行）
    cd /d D:\数据结构课设\code
    gcc -g -Wall -std=c99 -finput-charset=UTF-8 -fexec-charset=GBK *.c -o app.exe
    app.exe


三、重要注意事项（踩过坑，务必看）
----------------------------------------------------------------
  1) 编译时只传相对路径 / ASCII 文件名
     MinGW 的链接器（ld）无法处理中文路径的 -o 输出参数，
     直接写 gcc ... -o D:\中文目录\app.exe 会报
     "cannot open output file ... No such file or directory"。
     build.bat 已经用 cd + 相对路径的方式绕开了这个问题，
     所以你双击它、或在 VS Code 里构建都不会有问题。

  2) 中文字符串输出乱码
     源文件按 UTF-8 保存（VS Code 默认），编译时加
        -finput-charset=UTF-8   告诉 gcc 源文件是 UTF-8
        -fexec-charset=GBK      让运行时的字符串转成 GBK
     这样在普通 cmd 窗口里中文显示正常。build.bat 已包含这两个参数。

  3) 数组/变量命名不要用中文，注释和 printf 里的中文没问题。

  4) 每个 .c 文件都要能被独立编译；除非题目要求，不要写两个 main()。
