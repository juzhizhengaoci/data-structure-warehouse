  仓库管理系统 · 程序说明（数据结构课程设计 · 题目19）

一、系统概述
----------------------------------------------------------------
  存储结构：单链表（链式存储，题目硬性要求）
  开发语言：C（C99）
  编译工具：MinGW-w64 GCC 16.2.0
  代码规模：8 个文件，约 1000 行

二、文件清单与职责
----------------------------------------------------------------
  goods.h    公共头文件：结构体定义、常量、全部函数声明（接口层）
  main.c     程序入口：主菜单、删除操作、警戒值设置、启动/退出时自动读写
  list.c     链式存储基础：节点创建、尾插、按编号查、四字段判重、
             按名称模糊查、删除、计数、汇总、数据域交换、释放
  io.c       输入校验与输出：全部输入走 fgets + 数值合法性校验，
             表格化输出、交互录入
  file.c     持久化：data.txt 读写（| 分隔文本）、log.txt 流水日志（带时间戳）
  stock.c    业务核心：入库（判重累加）、出库（合法性校验）、查询、低库存警示
  sort.c     排序：冒泡排序、选择排序，统计比较次数/移动次数并做对比
  stat.c     统计：库存总览、多条件筛选、盘点表导出

三、功能对照（题目要求 → 实现位置）
----------------------------------------------------------------
  【基础功能（必做）】
  （1）导入货品信息        → file.c  file_load()       主菜单 11
  （2）入库（同四字段累加）→ stock.c stock_in()         主菜单 2
  （3）查询（编号/名称）   → stock.c stock_query()      主菜单 4
  （4）出库（合法性校验）  → stock.c stock_out()        主菜单 3
  （5）删除货品并存盘      → main.c  menu_delete()      主菜单 5
  （6）排序（按单价）      → sort.c  sort_menu()        主菜单 6
  （7）低库存补货警示      → stock.c stock_warn()       主菜单 7

  【拓展功能（题目要求至少选 1 个，本程序做了 4 个）】
  （1）统计总库存金额、出入库次数 → stat.c  stat_summary()   主菜单 8
  （2）合法性校验（出库不超库存、数量非负）→ stock.c stock_out() + io.c
  （3）出入库流水日志            → file.c  file_log()        自动写入 log.txt
  （4）多条件筛选（价格区间/厂家）→ stat.c  stat_filter()     主菜单 9
  （5）导出库存盘点表            → stat.c  stat_export()      主菜单 10

四、数据结构与文件格式
----------------------------------------------------------------
  typedef struct Goods {
      char   id[20];        /* 编号 */
      char   name[50];      /* 名称 */
      char   factory[50];   /* 生产厂家 */
      char   batch[20];     /* 批次 */
      int    qty;           /* 库存数量 */
      double price;         /* 单价 */
      struct Goods *next;   /* 链指针 */
  } Goods;

  data.txt  格式：编号|名称|生产厂家|批次|数量|单价
            以 # 开头的行是注释，解析时自动跳过
  log.txt   格式：[时间戳] 操作描述（追加写入，永不覆盖）

五、验收演示流程（建议按这个顺序演，能覆盖所有校验点）
----------------------------------------------------------------
  1. 启动程序（默认空仓库，提示未找到 data.txt）
  2. 选 2 入库：录 P001 螺丝刀 得力 20250301 数量100 单价15.50  → 提示"新货品入库成功"
  3. 选 2 再入库：编号/厂家/批次/单价完全相同，数量 50        → 演示"数量累加 100→150"
  4. 选 2 入库：同编号但**批次不同**                          → 演示"新增记录"（判重边界！）
  5. 选 3 出库：输入不存在的编号                              → 演示"未找到货品"
  6. 选 3 出库：输入超过库存的数量                            → 被输入层直接拦下
  7. 选 6 排序 → 按单价 → 升序 → 3(对比)                      → 演示两种算法比较/移动次数
  8. 选 7 低库存警示 / 8 统计报表 / 10 导出盘点表             → 演示统计与导出
  9. 选 0 退出，再重启程序                                    → 演示数据持久化成功

六、报告可直接引用的实测数据
----------------------------------------------------------------
  10 条记录、按单价升序排序：
      冒泡排序：比较 81 次，移动 57 次
      选择排序：比较 45 次，移动 15 次
  理论值：N=10 时选择排序比较次数恒为 N(N-1)/2 = 45，与实测一致。
  冒泡因"本趟无交换即提前结束"的优化，实际比较次数少于 N² 。

  时间复杂度：冒泡 O(N²)（最好 O(N)）、选择 O(N²)；
  空间复杂度：两者均为 O(1)（只在链表节点间交换数据域，无需额外数组）。
  查找：按编号为 O(N)（顺序查找）；可按哈希表索引优化。
