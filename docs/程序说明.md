一、系统概述
----------------------------------------------------------------
  存储结构：单链表（链式存储，题目硬性要求）
  开发语言：C（C99）
  编译工具：MinGW-w64 GCC 16.2.0
  代码规模：10 个 C 源文件 / 头文件，C 代码约 2680 行
            另含 Web 版前端页面 webui.html（383 行）
  第三方依赖：无，仅使用 C 标准库

二、文件清单与职责
----------------------------------------------------------------
  goods.h     公共头文件：结构体定义、常量、全部函数原型（契约层）
  main.c      程序入口：主菜单、删除操作、警戒值设置、测试数据生成、
              启动/退出时自动读写（控制层）
  list.c      链式存储基础：节点创建、尾插、按编号查、四字段判重、
              按名称模糊查、删除、计数、汇总、数据域交换、释放（数据层）
  io.c        输入校验与输出：全部输入走 fgets + 数值合法性校验，
              表格化输出、交互录入（基础服务层）
  file.c      持久化：data.txt 读写（| 分隔文本）、
              log.txt 流水日志（带时间戳）（基础服务层）
  stock.c     业务核心：入库（判重累加）、出库（合法性校验）、
              查询、低库存警示（业务层）
  sort.c      排序：冒泡、选择、直接插入、希尔、快速 五算法，
              统计比较次数 / 移动次数并做性能对比（业务层）
  stat.c      统计：库存总览、多条件筛选、盘点表导出（业务层）
  webserver.c Web 版服务器：原生 winsock2 手写 HTTP 服务（含独立 main）
  bench.c     并发压测工具（含独立 main）

  注：webserver.c / bench.c 各自带 main()，因此 build.bat 编译控制台版时
      故意排除它们，否则链接期报 duplicate main。

四、数据结构与文件格式
----------------------------------------------------------------
  typedef struct Goods {
      char   id[32];        /* 编号 */
      char   name[100];     /* 名称 */
      char   factory[100];  /* 生产厂家 */
      char   batch[32];     /* 批次 */
      int    qty;           /* 库存数量 */
      double price;         /* 单价 */
      struct Goods *next;   /* 链指针 */
  } Goods;

  字段长度以 goods.h 中的常量 ID_LEN / NAME_LEN / FACTORY_LEN /
  BATCH_LEN 为准，上表为当前实际取值。

  data.txt  格式：编号|名称|生产厂家|批次|数量|单价
            以 # 开头的行是注释，解析时自动跳过
  log.txt   格式：[时间戳] 操作描述（追加写入，永不覆盖）
  stock_report.txt  导出的库存盘点表（明细 + 汇总）

五、排序算法与实测数据（主菜单 6 → 算法 6）
----------------------------------------------------------------
  五种算法均直接作用于链表，只交换节点数据域，不额外申请数组，
  空间复杂度均为 O(1)：

      冒泡排序  O(N^2)，带"本趟无交换即提前退出"优化，最好 O(N)
      选择排序  O(N^2)，比较次数恒定 N(N-1)/2，移动次数少
      直接插入  O(N^2)，交换式实现，接近有序时表现好
      希尔排序  约 O(N^1.3)，间隔递减 gap = N/2, N/4, ..., 1
      快速排序  O(N log N) 平均，链表分区法，取首元素为基准

  10 条记录、按单价升序的实测值：
      冒泡排序：比较 81 次，移动 57 次
      选择排序：比较 45 次，移动 15 次
  理论值：N=10 时选择排序比较次数恒为 N(N-1)/2 = 45，与实测一致。
  冒泡因"本趟无交换即提前结束"的优化，实际比较次数少于 N²。

  Web 版压测（bench.c，25 并发 / 29 请求）：
      成功响应 24/29（82.76%），平均响应时间 5.21 ms，
      峰值响应时间 32 ms，常驻内存 9.3 MB，<10 ms 占比 70.83%
