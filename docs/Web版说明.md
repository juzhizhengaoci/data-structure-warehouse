================================================================
  仓库管理系统 · Web 版说明（前后端均由 C 语言实现）
================================================================

一、这是什么
----------------------------------------------------------------
  同一套业务逻辑（链式存储 + 出入库 + 排序 + 统计），提供两种交互方式：

    (1) 控制台版  app.exe     —— 菜单式黑窗口，验收演示用
    (2) Web 版    server.exe  —— 浏览器界面，跑在本机

  两个版本共用：
    · 同一份数据结构定义  goods.h
    · 同一套链表代码      list.c
    · 同一套排序代码      sort.c
    · 同一份数据文件      data.txt

  也就是说：在网页里入库一条货品，打开控制台版就能看到 —— 数据完全互通。


二、架构（为什么"后端"也是 C）
----------------------------------------------------------------
    浏览器 (HTML + CSS + JS)
             │  HTTP / JSON
             ▼
    server.exe  ── Winsock 手写 HTTP 服务（约 700 行 C 代码）
       │          不依赖任何第三方库，不用 CGI，不用 Node/Python
       │
       ├── list.c / sort.c      复用控制台版的链表与排序
       └── data.txt             磁盘持久化

  课程设计硬性要求"C 语言实现、交 exe"，因此后端坚持用 C 写，
  只把浏览器当作纯展示层（前端负责渲染，不参与任何业务计算）。
  这样既不违反要求，又拿到了"界面美观、交互性好"的评分点。


三、文件清单（Web 版新增）
----------------------------------------------------------------
  webserver.c      Web 版入口：HTTP 解析、路由、JSON、GBK⇄UTF-8 转码、全部接口
  webui.html       前端页面（单文件，内联样式与脚本，无外部依赖）
  build_web.bat    编译脚本（链接 -lws2_32）
  start_web.bat    一键启动（自动编译 + 开浏览器 + 起服务）
  server.exe       可执行文件

  注意：webserver.c 里也有 main()，所以 build.bat 已改为显式列文件，
       不能再对目录用 *.c 通配编译（会报重复 main）。


四、接口一览
----------------------------------------------------------------
  GET  /               前端页面
  GET  /api/list       货品列表 + 汇总统计（前端一次请求拿全）
  POST /api/in         入库   参数 id/name/factory/batch/qty/price
  POST /api/out        出库   参数 id/qty（校验：存在、>0、不超库存）
  POST /api/del        删除   参数 id
  POST /api/sort       排序   参数 field(1单价 2数量)/asc(1升0降)/algo(1冒泡 2选择 3对比)
  POST /api/limit      设置库存警戒值  参数 limit
  GET  /api/export     导出盘点表 stock_report.txt
  GET  /api/reload     从 data.txt 重新载入

  编码：请求体用 application/x-www-form-urlencoded（UTF-8 百分号编码），
        响应统一 application/json; charset=utf-8。


五、怎么运行
----------------------------------------------------------------
  方式一：双击 start_web.bat  → 自动编译、自动开浏览器，Ctrl+C 停止
  方式二：双击 build_web.bat 编译，再双击 server.exe（手动访问 localhost:8080）
  方式三：命令行  server.exe 8081   换端口（默认 8080 被占用时）

  服务只监听 127.0.0.1（本机），不对外网开放，因此不会触发 Windows 防火墙提示。


六、答辩时怎么说（建议话术）
----------------------------------------------------------------
  "系统提供两种运行模式：控制台模式和浏览器模式。
   两种模式共用同一套链式存储和算法模块，数据文件也是同一份。
   浏览器模式的后端依然是用 C 语言自己实现的 HTTP 服务（基于 Winsock），
   没有使用任何第三方框架，前端只负责界面渲染。"
  —— 全程 C 语言，符合课程设计要求，同时界面更直观。

八、已知限制
----------------------------------------------------------------
  1. 服务为单线程，一次只处理一个请求（教学演示足够，不适合高并发）
  2. 库存警戒值只存在内存中，重启服务后恢复默认 20
  3. 前端每 8 秒自动刷新一次列表（多开窗口时以最后操作为准）
  4. 仅监听 127.0.0.1，手机等外部设备无法访问（有意为之，避免开放端口）
